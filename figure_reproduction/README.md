# Editable figure candidate

Prepared locally, not published. Create an isolated Python3.12.12 environment and install the pinned requirements. Run these scripts from this directory:

    python dark/render_dark.py

Copied point estimates and saved intervals are unchanged; no statistical replay is required to render. Byte-identical outputs were confirmed only in the pinned plotting environment. Chirality drawings are exact finite illustrations, not judge measurements. Author approval and licence decisions remain pending.

The current paper also includes Figure4. Its existing render, data, source and environment record are in [held485/](held485/README.md). This packaging revision did not rerender it or repeat its statistical analysis.
